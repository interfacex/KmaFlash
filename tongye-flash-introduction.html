下载 Apple Silicon 版 ↓下载 Intel 版 ↓

同页 Flash 0.7.2（build 11） · macOS 14 或更新版本
Apple Silicon（arm64） / Intel（x86_64）
两种安装包均不附带内置阅读资料，首次启动没有阅读记录与笔记，请先导入自己的资料。模型列表仅保留无 API Key 的 Demo，使用 AI 前请配置自己的模型连接。

  1. 下载安装包

    在“关于本机”确认芯片类型，选择 Apple Silicon 或 Intel 安装包。

  2. 拖入应用程序

    双击打开 DMG，将「同页.app」拖到 Applications（应用程序）文件夹。

  3. 翻开你的第一本书

    从应用程序中打开「同页」，书房从空白开始，导入自己的 PDF、TXT、Markdown 或代码 ZIP 后即可阅读。

当前应用为本地签名版本，尚未公证。如系统阻止打开，请先确认安装包来源可信，再按照 macOS「系统设置 → 隐私与安全性」中的提示处理；无需关闭系统安全保护。
