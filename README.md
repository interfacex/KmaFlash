# 同页 · Flash

**人物相伴 · 阅读有得。** 同页是一款原生 Mac AI 阅读应用，把原文、陪读对话、角色导读和阅读笔记放在同一个书房。无需部署服务端，大模型由客户端直接连接。

## 从自己的阅读资料开始

应用不附带任何内置阅读资料。首次打开时书房为空，请导入自己的书籍、文章和代码工程，或粘贴正文与公开网页链接。升级会保留已有材料、笔记与阅读进度，不再自动添加阅读资料。

## 阅读与思考

- **原文阅读**：章节导航、页码定位、阅读进度；划选文字即可复制、记笔记、解释、讨论或标记“读到这里”。
- **伴读对话**：选择陪读角色，围绕当前章节持续追问；邀请 2–3 位角色同场讨论，比较不同观点。
- **角色导读**：流式生成章节导读，区分原文摘录与角色解读，引用可回到原文核对；点击本章人物卡，与书中人物对话。
- **阅读笔记**：一键保存回答、摘抄原文、记录自己的理解；支持编辑、返回来源和 Markdown 导出。共读记录按材料与章节保留。
- **工程阅读**：支持代码 ZIP/ZIP64 导入、目录与源码浏览、真实行号、选段提问和工程学习路线。
- **资料导入**：支持 PDF、TXT、Markdown、代码压缩包、公开网页链接与粘贴正文，提供进度、取消、重试和重复检测。

## 使用

要求 macOS 14 或更新版本。启动后先导入自己的阅读资料。在顶部切换原文、伴读、导读；从模型设置复制 Demo 为自定义模型，填写模型名称、服务地址及所需 API Key 后使用 AI 功能。

## 模型与数据

应用仅保留一个 Demo 配置示例，不附带可用模型、真实 API Key 或公司网关。Demo 不会发起网络请求；请复制为自定义模型并填写自己的配置。支持 OpenAI Chat Completions、Responses 兼容服务，可调整 Token 上限和生成参数。

材料、笔记与记录保存在本机；请求 AI 时会把相关阅读内容发送至所选模型服务。自定义 API Key 保存在 macOS 钥匙串。可通过“模型设置 → 打开本地数据目录”备份本地资料。人物回答属于 AI 演绎，请结合原文核对。

## 本地构建

安装 macOS Command Line Tools，运行 `./scripts/package-dmg.sh arm64` 或 `./scripts/package-dmg.sh x86_64`，生成对应架构的应用、DMG 和 SHA-256 校验文件。本次构建使用 Swift 6.1.2；当前安装包为 0.7.2（build 11），不包含阅读资料、阅读记录、笔记或真实模型凭据。
